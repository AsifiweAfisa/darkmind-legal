Privacy Policy

Last updated: 2026

DarkMind Auto ("the Tool") is a personal automation project used by a single operator to generate and publish content to their own social media accounts. This policy explains what data the Tool interacts with.

1. What Data Is Used

The Tool uses API access tokens, issued directly by each connected platform (YouTube, TikTok, Instagram, Facebook, X), to publish video content on behalf of the operator's own accounts. No data belonging to any other individual or third party is collected, stored, sold, or shared.

2. Data Storage

Generated video content, associated metadata (captions, hashtags, scene descriptions), and API credentials are stored locally on infrastructure controlled by the operator. This data is not transmitted to or accessed by any third party beyond the destination social media platforms themselves, for the sole purpose of publishing content.

3. Third-Party Services

The Tool interacts with the following third-party APIs strictly to generate and publish content:

  • TikTok Content Posting API
  • YouTube Data API
  • Meta Graph API (Instagram and Facebook)
  • X API
  • AI content-generation and text-to-speech providers
  • Stock footage providers

Each of these services is governed by its own privacy policy, which applies to any data exchanged with them.

4. No End-User Data Collection

This Tool does not have public end users. It does not collect analytics, cookies, or personal information from any visitor, viewer, or third party interacting with the published content.

5. Changes to This Policy

This policy may be updated at any time without prior notice.

6. Contact

For questions regarding this policy, contact the operator directly.
